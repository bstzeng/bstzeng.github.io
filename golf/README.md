# 翠嶺高爾夫 · 擬真 3D 高爾夫 18 洞

Three.js 做的 3D 高爾夫。所有地形、材質、樹都是程式產生（沒有外部圖片）；天空用 Three.js 的物理天空模型（Preetham）。

## 球場
- 18 洞、標準桿 72、全長 7,085 碼（約 6,478 m）。每洞長度沿中心線量，跟冠軍場一樣長：短洞 156–221 碼、四桿洞 352–465 碼、五桿洞 515–562 碼
- 狗腿洞、雙彎五桿洞；球道沙坑、橫跨沙坑、果嶺沙坑、果嶺前水塘、沿邊湖、發球台前水域、小溪
- 地形：大範圍起伏、長草區土丘、發球台平台、果嶺抬高並有傾斜與起伏；界外白樁、水域紅樁、100/150/200 碼樁
- 每洞兩側是樹林，長草區偶爾有單棵大樹（打到會擋球）

## 物理
- 空氣阻力＋旋轉升力（馬格努斯），阻力／升力係數依旋轉比；後旋會衰減
- 風隨高度變強（對數風剖面），有陣風；雨天球比較不滾
- 各球桿以實測球速、發射角、後旋校正：一號木飛行 245 碼（總 272）、七號鐵 162 碼……
- 落地依地面種類反彈與減速（球道、長草、深長草、沙坑、果嶺），後旋讓球在果嶺上煞住
- 滾動：坡度加速、草的阻力，果嶺約等於果嶺速度 10–11 呎；洞口判定（太快會彈出）、旗桿、樹冠與樹幹
- 球位影響：長草、沙坑會掉距離、少旋轉、散布變大；落水罰一桿抛球；OB 罰一桿回原處

## 玩法
- 瞄準：拖曳畫面或 ◀ ▶；換桿 ▲ ▼；球童會建議球桿與力道（考慮高低差與風）
- 預定力道、左曲／直球／右曲、低飛／標準／高飛；黃色預測線與落點圈
- 揮桿量表（三按）：開始 → 力道 → 準度；簡單模式一按就揮
- 推桿：果嶺格線＋沿下坡流動的光點
- 鏡頭：瞄準、落點、空拍；擊球後追球，落地前切到落點鏡頭；每洞開頭空拍飛越
- 天氣：晴、多雲、陣雨、起霧；早晨、午後、黃昏；風速可選
- 記分卡：小鳥／老鷹畫圈、柏忌畫方框；上球道率、標準桿上果嶺、推桿數

# 溪山行旅

以中國古典山水市集畫卷為視覺參考的 3D 場景，使用 JavaScript + Three.js（r170）製作。所有模型都在程式裡程序化生成，沒有使用外部模型或貼圖，單位是公尺，水面是 y = 0。

入口：`index.html`（網址 `/xishan/`）

## 三個入口
- **環繞全景**：從河對岸稍高處斜看市鎮，可以拖曳旋轉、縮放
- **步行探索**：第一人稱。WASD／方向鍵移動、拖曳看四周、Shift 快跑、E 上下船、M 開輿圖（點地圖可以直接傳送）；平板用左下角搖桿
- **搭船遊河**：坐在烏篷客船船頭，從北岸渡口出發，往西繞過河灣、穿過虹橋到上游折返，再穿橋回到南岸渡口

## 程式結構（`js/`）
| 檔案 | 內容 |
|---|---|
| `layout.js` | 世界配置：河道、小溪、地形高度、橋、碼頭、道路、建築與樹的位置、船的航線、行人路線、走路的地面與碰撞規則（不依賴 Three.js，可以在 Node 測） |
| `geo.js` | 合併網格的批次器、參數曲面、屋頂產生器（廡殿／歇山／懸山／腰簷／攢尖，含凹曲屋坡、翼角起翹、正脊、戧脊、垂脊、鴟吻、瓦當） |
| `build.js` | 建築：台基、柱、斗拱、額枋、格扇門窗、商鋪、兩層酒樓、民居、貨棧、大殿（重簷歇山＋迴廊）、配殿、水榭、門樓、官署、白牆院落、高台（石券門洞＋雙側石階＋後方石階）、觀景亭、攤位與帳篷 |
| `bridge.js` | 虹橋（朱紅水中立柱、木拱、欄杆、華表）與朱欄小橋 |
| `boats.js` | 斷面放樣的弧形船身：烏篷客船、畫舫、貨船 |
| `plants.js` | 程序化枝幹＋葉簇：垂柳（擺動的柳條）、松、柏、闊葉古樹、桃杏，風吹擺動在 shader 裡 |
| `people.js` | 行人、攤販、挑擔、搬貨船工、船夫與走路動畫 |
| `env.js` | 地形網格、道路、砌石岸線、碼頭與繫船樁、遠山、天空、霧、水面（平面倒影＋流動細波＋船尾浪） |
| `map.js` | 小地圖與輿圖 |
| `main.js` | 渲染、光影、三種模式、船隻航行與停靠、上下船、測試介面 `window.xishan` |

## 測試
```bash
python3 -m http.server 8765
node xishan/tests/run-tests.cjs
```
會在無頭瀏覽器裡實際載入場景，測三件事：
1. **橋面能走通**：從門樓後面出發，穿過門洞、走過虹橋最高點、進到東岸市街
2. **渡船穿橋不穿模**：沿整條航線檢查船身外框到立柱的距離，以及船上最高點（船夫斗笠）到橋底的淨空（同時用公式與對橋面網格打射線）
3. **碼頭可以上下船**：在北岸渡口登船、坐到南岸渡口下船、走石階上岸

另外會走一遍完整步行路線：市街 → 御街 → 高台 → 大殿台基 → 宮苑 → 山徑 → 觀景亭。

# 清明上河圖 · 活的畫卷

以《清明上河圖》為題的 3D 街道（Three.js，全部程序化建模）。畫卷從右往左讀：

| 段落 | 內容 |
| --- | --- |
| 郊野 | 茅屋、田地、小溪木橋；驢隊馱炭進城，掃墓歸來的轎子隊伍（轎頂插柳） |
| 汴河 | 漕船停泊、苦力扛米袋上岸、縴夫在北岸拉船、小船來往 |
| 虹橋 | 無柱編木拱橋，橋上攤傘與人潮；大船放倒桅杆穿過橋下，橋上、岸邊的人揮手驚呼 |
| 街市 | 店鋪、腳店與孫羊店的彩樓歡門、太平車、牛車、獨輪車、騎驢騎馬的人 |
| 城門 | 城樓、門洞，駱駝隊穿城而過 |
| 城內 | 十字街、趙太丞家、說書人與聽眾、寺院 |

## 兩種看法

- **畫前觀賞**：正交相機固定俯角，只能左右捲動（拖曳、滾輪、← →、下方導覽條、「展卷」自動捲動）。畫面加上絹本設色、墨線、絹紋與留白雲霧的後製。
- **走進畫中**：第一人稱自由走動（WASD／拖曳／平板搖桿），可以走上虹橋、穿過城門；從畫前切換時會落在畫面中央最近的路上。

## 檔案

- `js/plan.js`：世界配置（河道、虹橋、城門、道路、建築、攤位、樹、船、碰撞與地面）
- `js/world.js`：地形、路、虹橋、城門、彩樓歡門、攤傘、招牌
- `js/life.js`：人群（InstancedMesh）、動作、牲畜、車、轎、放桅大船
- `js/sim.js`：所有會動的東西的行為
- `js/main.js`：渲染、兩種模式、繪畫後製、操作介面、測試介面
- 共用 `../xishan/js/` 的屋頂、建築、樹、船身、水面、天空模組

## 測試

```bash
python3 -m http.server 8765
node qingming/tests/run-tests.cjs shots
```

說明：場景是依照對這幅畫內容的了解重新構成的，不是逐筆臨摹原畫。

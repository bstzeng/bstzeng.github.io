# 公仔桌球 · 3D 桌球

Three.js 做的公仔風桌球，造型、音效全部程式產生。共用模組在 `../sportkit/`。

## 玩法
- 滑鼠移動球拍：球拍只在桌面高度的平面上移動，球在你這邊彈一次後碰到球拍就自動回擊
- 打到球拍左右邊，球往那一邊飛；往前推越快球越快越深（太用力會出界）
- 擊球瞬間球拍的速度決定旋轉：往前推＝上旋、往後拉＝下旋、左右刷＝側旋（空中會轉彎）
- 發球：點一下滑鼠，點的時候移動球拍可以加旋轉
- 11 分制、10 平要贏 2 分、每 2 分換發球
- 難度：電腦的移動速度、反應時間、讀旋轉能力、失誤率、球速與旋轉

## 物理
重力、空氣阻力、馬格努斯力；桌面反彈時旋轉和摩擦會讓上旋往前衝、下旋煞住。回擊用「射擊法」反覆模擬，解出會落在目標點且過網的初速。

# 公仔網球 · 3D 網球

Three.js 做的公仔風網球，造型、觀眾、音效全部程式產生。共用模組在 `../sportkit/`。

## 玩法
- 小人以固定速度跑向滑鼠游標（地上紅圈）
- 球進到小人腳下白圈（手臂＋球拍範圍）就自動回擊；球在範圍正中間最快最深
- 球在右邊打到往左飛、在左邊往右飛；早擊打斜線；球很高時會殺球
- 發球：點一下拋球，在最高點再點一下；游標左右選落點（黃圈）；兩次機會
- 計分：15、30、40、平分要連贏 2 分；先拿 4 局獲勝，每局換發球
- 難度：電腦的跑速、反應、球速、角度、失誤與發球失誤率
